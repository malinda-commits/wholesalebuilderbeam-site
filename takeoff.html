How to figure linear feet for a box beam order.

A practical overview for home builders, GCs and remodelers counting runs from plans or a site measure and writing the linear feet on the order. Sizes are in the sizing guide. Bid wording is in the bid spec guide. Mounting is in the install guide. Delivery is in the delivery guide.

This page is guidance for counting linear feet. The examples are illustrative math, not quotes. It is not a stamped specification. These beams are decorative and non-structural.

On this page: Count the runs · Multiply by length · Pieces over 24 ft · Overage · On the order form

Count the runs

Start from the plans or from a site measure. A run is one beam line, end to end, along the finished ceiling.

Parallel. The beams run the same direction, spaced across the ceiling. Count one run for each beam.

Grid or coffered. Beams run both ways and cross. Count every run in both directions for its full length. Do not subtract where the runs cross.

Ridge plus purlins. Count the ridge as one run, then count each purlin as its own run.

Perimeter. Count the beam lines around the room: two runs along the length and two runs along the width. If a wall, soffit, or opening breaks a side, count each piece of that side.

Where a wall, soffit, or break splits a line, count the pieces the way you will order them. Measuring each run end to end, including walls, soffits, or breaks, is in the sizing guide. This page turns those runs into linear feet.

Multiply runs by length

Linear feet are the lengths of the runs, added together. When the runs are the same length, multiply the number of runs by that length.

Worked example, parallel runs. Four parallel beams across a 16 ft room: 4 × 16 = 64 linear feet.

That is illustrative math, not a quote.

Break a long run into pieces

Each piece can be up to 24 feet. A run longer than 24 feet is more than one piece. Break that run into pieces of 24 feet or less. The linear feet stay the length of the run. The split only names the pieces.

Worked example. A run measures 40 ft. Two pieces, 24 ft and 16 ft, cover it: 24 + 16 = 40 linear feet.

That is illustrative math, not a quote.

On site, pieces are cut or butted so the run meets cleanly. Mounting is in the install guide.

Overage for cuts and fitting

Cuts and fitting can use more material than the measured run. Whether to add extra linear feet, and how much, is the builder's call. This page does not set an overage percentage.

The examples above are the measured runs only. They do not include extra. Order the linear feet you decide to buy, and write them as piece lengths and quantities.

Enter height, width, and linear feet

On the order form, set the height and the width. Each is 4, 6, 8, 10, or 12 inches. Larger than 12 inches is quoted on request. Note that size on the order. Sizes are in the sizing guide.

Under Lengths, add a row for each piece length and the quantity of that length. The form totals the linear feet. Add another length for more rows of the same size and finish.

Use one line per size or finish. The height, the width, and the finish on the form apply to every length row. A different height, width, or finish is its own line. Put a second size or finish in the notes on the order form so it stays separate.

Choose prestained or unfinished on that line. Bid wording is in the bid spec guide. Delivery is in the delivery guide.
